# Procedência

As seis skills deste catálogo foram adaptadas das skills de autoria do projeto [EsilvaSoft/Xenogenesis](https://github.com/EsilvaSoft/Xenogenesis), em `.agents/skills/`, consultadas no checkout cujo HEAD era `b6a33a2bb5adb4f4ba43df416b1362f16f4fa1ad`.

O checkout local foi a fonte efetivamente lida; o hash identifica seu HEAD e não certifica que todo arquivo consultado já estivesse commitado. `provenance.json` registra também SHA-256 dos bytes lidos, permitindo identificar exatamente as fontes locais da adaptação.

| xenogenesis-escrever-task | skill-base-escrever-task |
| xenogenesis-escrever-pendencias | skill-base-escrever-pendencias |

| xenogenesis-aplicar-respostas | skill-base-aplicar-respostas |
| xenogenesis-orquestrar-execucao | skill-base-orquestrar-execucao |

A skill de balanceamento não foi incluída. As adaptações retiram regras do jogo, tecnologias, caminhos e políticas operacionais particulares. Preservam rastreabilidade, distinção entre proposta e aprovação, evidências de aceite e coordenação por dependências. O Xenogenesis não é alterado nem exigido para usar este catálogo.
