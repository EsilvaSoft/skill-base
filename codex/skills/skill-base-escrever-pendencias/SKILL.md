# Escrever pendências

Siga as instruções e convenções do projeto. Pesquise a documentação existente antes de criar novos registros. Preserve IDs, histórico e alterações alheias. Use os modelos abaixo apenas se o projeto não tiver formato próprio.

1. Consulte requisitos, decisões vigentes e perguntas já registradas, inclusive encerradas.
2. Separe o que já foi decidido da pergunta ainda aberta. Reutilize a pendência que cobre o mesmo assunto.
3. Registre pergunta, fontes, alternativas, recomendação proposta e impacto nas entregas.
4. Bloqueie somente o trabalho que depende da resposta. Uma recomendação não encerra a dúvida.
5. Confira links e mantenha uma única fila de pendências.

Modelo: [Pendência](assets/modelo-pendencia.md).

Ao entregar, informe arquivos alterados, verificações realizadas e pendências. Editar esta skill não autoriza executar seu fluxo no consumidor.
