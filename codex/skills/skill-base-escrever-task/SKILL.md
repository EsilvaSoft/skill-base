# Escrever Tasks

Siga as instruções e convenções do projeto. Pesquise a documentação existente antes de criar novos registros. Preserve IDs, histórico e alterações alheias. Use os modelos abaixo apenas se o projeto não tiver formato próprio.

1. Identifique o delta necessário e procure Tasks que já o cubram.
2. Vincule o requisito ou US real conforme a organização do projeto; não imponha uma hierarquia nova.
3. Defina entradas, saídas, limites, contratos afetados, dependências e critérios de conclusão.
4. Indique verificações adequadas à stack e ao comportamento. Testes planejados não são testes executados.
5. Registre lacunas que impedem a entrega e confira os vínculos. Task nova permanece aberta.

Modelo: [Task](assets/modelo-task.md).

Ao entregar, informe arquivos alterados, verificações realizadas e pendências. Editar esta skill não autoriza executar seu fluxo no consumidor.
