# Propor respostas

Siga as instruções e convenções do projeto. Pesquise a documentação existente antes de criar novos registros. Preserve IDs, histórico e alterações alheias. Use os modelos abaixo apenas se o projeto não tiver formato próprio.

1. Leia as perguntas selecionadas, decisões vigentes e fontes relacionadas.
2. Para cada pergunta residual, proponha resposta, fundamento, alternativas, impactos e limites.
3. Identifique o documento como proposta para revisão e registre autoria real e fontes consultadas.
4. Preserve a parte já decidida. Não altere regras canônicas nem encerre pendências ao apresentar sugestões.
5. Confira coerência com as fontes e destaque as escolhas que precisam de decisão.

Modelo: [Respostas propostas](assets/modelo-respostas.md).

Ao entregar, informe arquivos alterados, verificações realizadas e pendências. Editar esta skill não autoriza executar seu fluxo no consumidor.
